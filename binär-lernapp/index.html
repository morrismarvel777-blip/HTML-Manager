Stellenwerte: Das Grundprinzip

Die Basis bestimmt die erlaubten Ziffern und die Stellenwerte. Von rechts beginnt jede Zahl mit der Potenz 0.

Dezimal (Basis 10): 1, 10, 100, 1000, ... Binär (Basis 2): 1, 2, 4, 8, 16, ... Hex (Basis 16): 1, 16, 256, 4096, ...

Beispiel: 53810 = 5 × 102 + 3 × 101 + 8 × 100.

Binär → Dezimal

  1. Schreibe unter jede Stelle die Zweierpotenz.
  2. Multipliziere jede Potenz mit der Ziffer 0 oder 1.
  3. Addiere nur die Stellen, an denen eine 1 steht.
110101₂ = 32 + 16 + 0 + 4 + 0 + 1 = 53₁₀

Dezimal → Binär

  1. Teile die Zahl wiederholt durch 2.
  2. Notiere bei jeder Division den Rest 0 oder 1.
  3. Lies die Reste am Schluss von unten nach oben.
13 : 2 = 6 Rest 1 6 : 2 = 3 Rest 0 3 : 2 = 1 Rest 1 1 : 2 = 0 Rest 1 → 13₁₀ = 1101₂

Binär ↔ Hexadezimal

Eine Hex-Ziffer ersetzt genau vier Bits. Gruppiere eine Binärzahl deshalb von rechts in Viererblöcke; links darfst du Nullen ergänzen.

1010 1101₂ = AD₁₆ A=10, B=11, C=12, D=13, E=14, F=15

Merkregel: Binär ↔ Hex geht direkt in Vierergruppen. Der Umweg über Dezimal ist nicht nötig.

Binäre Addition

Rechne von rechts nach links. Schreibe jeden Übertrag über die nächste Spalte links.

0 + 0 = 00 + 1 = 1 1 + 1 = 101 + 1 + 1 = 11

Bei 10 schreibst du 0 und überträgst 1. Bei 11 schreibst du 1 und überträgst 1.

Binäre Multiplikation

  1. Multipliziere mit jeder Ziffer des unteren Faktors.
  2. Bei 1 übernimmst du die obere Zahl, bei 0 entsteht eine Nullzeile.
  3. Verschiebe jede neue Teilzeile eine Stelle nach links.
  4. Addiere die Teilprodukte. Nutze oben bei Bedarf mehrere Überträge wie 1+1.
1011₂ × 101₂ = 110111₂

Übungsaufgaben mit Prüfung

Jeder Aufgabentyp erzeugt beliebig viele neue Zahlen. Dein Rechenweg bleibt frei, die Ergebnisse werden sofort kontrolliert.

Aufgabe 1 Wandle 1101012 in eine Dezimalzahl um. Der Rechenweg soll sichtbar sein.
Binär → Dezimal
1101012 = 32 + 16 + 4 + 1 = 53.
Aufgabe 2 Wandle 3710 in eine Binärzahl um. Nutze den Restweg oder das Zerlegen.
Dezimal → Binär
3710 = 1001012.
Aufgabe 3 Wandle 17310 zuerst in Binär und dann in Hexadezimal um.
Dezimal → Binär → Hex
17310 = 101011012 = AD16.
Aufgabe 4 Wandle A9E16 zuerst in eine Binärzahl und dann in eine Dezimalzahl um.
Hex → Binär → Dezimal
A9E16 = 1010 1001 11102 = 271810.
Aufgabe 5 Addiere 11101102 + 10012. Schreibe die Ueberträge mit auf.
Binäre Addition
11101102 + 10012 = 11111112.
Aufgabe 6 Multipliziere 10112 x 1012 und achte auf die Verschiebung der Teilprodukte.
Binäre Multiplikation
10112 x 1012 = 1101112.
Aufgabe 7 Wie lautet die grösste Zahl mit 3 Dezimalstellen und mit 6 Binärstellen?
Maximalwerte
Mit 3 Dezimalstellen ist die grösste Zahl 999. Mit 6 Binärstellen ist sie 1111112 = 63.

Schnellformeln

Die wichtigsten Regeln komprimiert, damit du beim Lernen schnell nachschlagen kannst.

Maximalzahl

n Dezimalstellen: 10^n - 1 n Binärstellen: 2^n - 1

Binär + Binär

0 + 0 = 0 0 + 1 = 1 1 + 1 = 10 1 + 1 + 1 = 11

Hex-Umrechnung

1 Hex-Ziffer = 4 Bits Beispiel: A9E = 1010 1001 1110
