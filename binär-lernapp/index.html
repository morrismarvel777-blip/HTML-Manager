Kurztheorie zum Merken

Wie auf den Blättern: erst die Idee, dann das Beispiel, dann die Rechenregel.

1. Dezimalsystem

Das Dezimalsystem benutzt die Ziffern 0 bis 9. Jede Stelle steht für eine Potenz von 10.

538 = 5 x 10^2 + 3 x 10^1 + 8 x 10^0

Merkregel: Jede Stelle hat einen Wert, der von ihrer Position abhängt.

2. Binärsystem

Computer arbeiten mit zwei Zuständen. Darum werden nur die Ziffern 0 und 1 verwendet.

110101_2 = 1 x 2^5 + 1 x 2^4 + 0 x 2^3 + 1 x 2^2 + 0 x 2^1 + 1 x 2^0

Von rechts nach links werden die Stellen mit 1, 2, 4, 8, 16, 32, ... gewichtet.

3. Hexadezimalsystem

Basis 16: Ziffern 0-9 und A-F. Eine Hex-Ziffer entspricht immer genau 4 Bits.

A = 10, B = 11, C = 12, D = 13, E = 14, F = 15

Das macht lange Binärzahlen viel kompakter.

4. Schriftliche Verfahren

  • Addition: von rechts nach links rechnen und Ueberträge mitnehmen.
  • Multiplikation: Teilprodukte nach Stellenwert verschieben.
  • Binäre Multiplikation: 1 x Zahl = Zahl, 0 x Zahl = 0.

Uebungsaufgaben mit Prüfung

Die Aufgaben sind an die Arbeitsblätter angelehnt. Du kannst den Rechenweg daneben notieren und die Antwort kontrollieren.

Aufgabe 1 Wandle 1101012 in eine Dezimalzahl um. Der Rechenweg soll sichtbar sein.
Binär → Dezimal
1101012 = 32 + 16 + 4 + 1 = 53.
Aufgabe 2 Wandle 3710 in eine Binärzahl um. Nutze den Restweg oder das Zerlegen.
Dezimal → Binär
3710 = 1001012.
Aufgabe 3 Wandle 17310 zuerst in Binär und dann in Hexadezimal um.
Dezimal → Binär → Hex
17310 = 101011012 = AD16.
Aufgabe 4 Wandle A9E16 zuerst in eine Binärzahl und dann in eine Dezimalzahl um.
Hex → Binär → Dezimal
A9E16 = 1010 1001 11102 = 271810.
Aufgabe 5 Addiere 11101102 + 10012. Schreibe die Ueberträge mit auf.
Binäre Addition
11101102 + 10012 = 11111112.
Aufgabe 6 Multipliziere 10112 x 1012 und achte auf die Verschiebung der Teilprodukte.
Binäre Multiplikation
10112 x 1012 = 1101112.
Aufgabe 7 Wie lautet die grösste Zahl mit 3 Dezimalstellen und mit 6 Binärstellen?
Maximalwerte
Mit 3 Dezimalstellen ist die grösste Zahl 999. Mit 6 Binärstellen ist sie 1111112 = 63.

Schnellformeln

Die wichtigsten Regeln komprimiert, damit du beim Lernen schnell nachschlagen kannst.

Maximalzahl

n Dezimalstellen: 10^n - 1 n Binärstellen: 2^n - 1

Binär + Binär

0 + 0 = 0 0 + 1 = 1 1 + 1 = 10 1 + 1 + 1 = 11

Hex-Umrechnung

1 Hex-Ziffer = 4 Bits Beispiel: A9E = 1010 1001 1110
